# 品类竞品主图与详情页抓取分析方案

## 1. 目标

根据客户提供的产品链接和所属行业/品类，自动或半自动抓取行业 Top 3 竞品的主图、详情页内容，并输出一份完整策划方案：

- 竞品主图分析：画面主体、卖点表达、构图、色彩、场景、人群、信任背书。
- 竞品详情页结构分析：首屏、痛点、卖点、参数、场景、对比、评价、FAQ、促销转化模块。
- 目标客群与视觉表现分析：购买人群、使用场景、价格敏感度、审美偏好、决策因素。
- 客户产品对比分析：信息完整度、视觉表现、卖点表达、信任感、转化路径。
- 输出优化方案：主图方向、详情页框架、文案策略、模块顺序、视觉风格、拍摄/设计建议。

## 2. 输入字段

建议使用 `input_template.csv` 作为输入表，每行一个客户产品。

必填字段：

- `client_product_url`：客户产品链接。
- `industry`：行业，例如：户外露营、美妆护肤、母婴用品、宠物用品。
- `category_keyword`：平台搜索关键词，例如：camping chair、portable blender。
- `platform`：平台，例如：Amazon、淘宝、天猫、京东、1688、独立站。

选填字段：

- `brand_name`：客户品牌名。
- `target_market`：目标市场，例如：美国、欧洲、中国大陆。
- `price_range`：客户产品价格区间。
- `notes`：特殊要求，例如：只分析高端竞品、不要低价白牌、关注女性用户。

## 3. 竞品 Top 3 获取逻辑

不同平台的 Top 3 判定方式不同，建议优先使用以下规则：

1. 搜索 `category_keyword`。
2. 过滤广告、无关品类、异常低价、重复链接。
3. 优先选择自然排名靠前、销量/评论/评分表现稳定的产品。
4. 如果平台有榜单，优先使用 Best Seller、热销榜、类目榜。
5. 输出 3 个竞品链接，并记录选择理由。

如果平台反爬严格，可以采用半自动流程：人工提供 3 个竞品链接，系统负责抓取、整理和分析。

## 4. 抓取内容

### 客户产品

- 标题
- 主图和副图
- 价格
- 规格参数
- 卖点 Bullet Points
- 详情页图片/模块
- 评论摘要，如可获取
- 品牌信息

### 竞品产品

- 产品链接
- 标题
- 主图
- 副图
- 详情页长图/模块
- 价格
- 销量、评论数、评分，如可获取
- 核心卖点
- 页面结构顺序

## 5. 图片与页面分析维度

### 主图分析

- 商品是否足够突出。
- 背景是否干净或有场景感。
- 是否展示核心差异点。
- 是否有人物/手部/使用场景。
- 是否有尺寸、功能、材质、套装等信息辅助。
- 色彩是否符合品类和客群预期。
- 首屏缩略图是否有点击吸引力。

### 详情页结构分析

建议拆成以下模块：

1. 首屏价值主张：一句话说明为什么买。
2. 痛点共鸣：用户当前遇到的问题。
3. 核心卖点：3-5 个最强理由。
4. 使用场景：家用、户外、办公、礼品等。
5. 细节证明：材质、工艺、尺寸、结构、认证。
6. 对比模块：与普通产品/旧款/竞品对比。
7. 信任模块：评价、证书、质保、品牌背书。
8. 购买决策模块：规格、套装、适配人群、FAQ。

## 8. 推荐落地方式

### 第一阶段：半自动 MVP

- 人工输入客户链接、行业、关键词。
- 系统搜索或人工补充 Top 3 竞品链接。
- 脚本抓取网页文字、图片 URL、页面截图。
- AI 分析图片和页面结构。
- 自动生成 Markdown 报告。

### 第二阶段：自动化增强

- 增加平台适配器：Amazon、淘宝、天猫、京东、1688、独立站。
- 增加反爬处理：浏览器渲染、登录态、等待加载、截图留档。
- 增加图片下载和视觉模型分析。
- 增加报告导出为 Word/PDF。
- 增加历史案例库，用于沉淀行业模板。

## 9. 注意事项

- 电商平台规则经常变化，抓取应遵守平台条款和访问频率限制。
- 对淘宝、天猫、京东等平台，通常需要浏览器登录态，建议优先用浏览器自动化截图和结构提取。
- 对 Amazon，可优先抓取搜索结果、主图、A+ 页面模块、评论摘要。
- 对独立站，可直接抓取 HTML、图片、CSS 风格、页面截图。
- 竞品分析可以借鉴框架和表达逻辑，但不要复制图片、文案和设计。

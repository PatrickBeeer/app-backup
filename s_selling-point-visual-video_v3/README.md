# Run and deploy standalone app

This app is integrated for Unityshop standalone hosting and routes all AI requests through API Manager.

## Run Locally

**Prerequisites:** Node.js, npm/pnpm, running app-manager stack


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Production Route

- Standalone: `/standalone/s_selling-point-visual-video_v3/`
- Shell launch: `/app/s_selling-point-visual-video_v3`

# 参考台词高度仿写设计

日期：2026-08-13

## 目标

在保留参考视频原有分镜、语速和口播结构的基础上，让新商品台词高度接近原视频的表达方式，同时保证所有商品事实只来自用户上传的新商品资料。

成功标准：

- 自动取得带时间轴的参考台词。
- 新台词逐段对应参考台词，保留开场方式、句式长度、语气、卖点顺序、停顿和促单节奏。
- 品牌、商品名、价格、款式、袖长、材质、颜色、规格、功效等事实全部替换为新商品资料；缺失事实不得编造。
- 参考台词与新商品冲突时，新商品事实具有绝对优先级。
- 确认页可并排查看原台词和新台词，并在付费生成前修改新台词。
- 不向 Seedance 上传独立参考音频，视频请求继续保持 `audioUrls=[]`。

## 方案选择

采用本地 Whisper 自动转写。应用通过 `@huggingface/transformers` 运行 `onnx-community/whisper-small`，不新增语音云服务或 API Key。模型首次使用时下载到本机缓存，后续复用。

智算谷当前公开文档没有独立 ASR 接口；DeepSeek 是文本模型，不能直接听取视频。让视频生成模型自行理解原台词无法为 DeepSeek 提供可检查的逐句文本，因此不作为文案生成依据。

## 数据流

1. FFmpeg 将参考视频音轨解码为 16 kHz、单声道浮点 PCM，直接交给本地转写器。音频不写入项目目录，不上传对象存储。
2. Whisper 以中文转写模式运行，返回带时间戳的文本块。
3. 转写块按时间重叠关系对齐到现有 `SpeechSegment`；无法精确对齐的短块合并到最近语音段。
4. DeepSeek 接收：逐段原台词、语音时间轴、分镜时间、新商品事实和禁止表达。
5. DeepSeek 为每个语音段输出一条新台词。服务端忽略模型返回的时间值，始终使用本地检测到的原始时间轴。
6. 确认页显示“参考原台词 / 新商品台词”对照。用户可保存新台词后再确认生成。
7. Seedance 只收到参考视频、人物/商品图片和最终新台词提示词，不收到独立音频文件。

## 模块边界

### 本地转写器

新增 `ReferenceTranscriber` 接口和 Transformers.js 实现。输入为参考视频路径及 FFmpeg 路径，输出为 `ReferenceTranscriptSegment[]`。

转写器负责：

- 从 FFmpeg stdout 读取 PCM，避免创建 MP3/WAV 文件。
- 懒加载并复用 Whisper pipeline，避免每个项目重复初始化模型。
- 使用中文转写任务和时间戳输出。
- 将底层下载、解码和推理错误转换为简短的中文错误。

模型名由 `WHISPER_MODEL` 配置，默认 `onnx-community/whisper-small`。测试不下载真实模型，通过注入 pipeline factory 验证行为。

### 文案仿写器

扩展 `ProjectAnalyzer` 输入，加入只读的 `referenceTranscript`。DeepSeek 提示词明确以下优先级：

1. 新商品事实和禁止表达。
2. 原语音段时间长度。
3. 原台词的修辞结构、语气、信息顺序和节奏。

提示词禁止逐字复制完整原句；商品事实词必须重写，非商品型口头衔接词可保留。返回数量必须与语音段数量一致。

### 项目数据

`ProjectAnalysis` 新增 `referenceTranscript`。旧项目读取时该字段可缺省，前端按空数组处理，保证已有项目兼容。

`ScriptLine` 结构保持不变。新增付费确认前的脚本更新接口，只允许修改 `READY_TO_CONFIRM` 项目；拒绝空文案、段落数量变化和禁止表达，并保留原时间轴及行 ID。

## 界面

确认页将原来的单列口播改为两列对照：

- 左侧为只读参考原台词。
- 右侧为可编辑的新商品台词。
- 每行显示共同的开始和结束时间。
- “保存新台词”与“确认方案并生成”分开；有未保存修改时禁止进入付费生成。

转写失败时左侧显示“未能取得参考台词”，右侧仍显示当前确定性商品文案，并在警告区说明已经降级。

## 错误与降级

- 无音轨：跳过 Whisper，沿用按镜头生成的商品事实文案。
- Whisper 下载、解码或推理失败：记录分析警告，继续使用当前文案流程，不让项目失败。
- Whisper 返回空文本：视为转写失败并降级。
- DeepSeek 失败或输出无效：使用现有商品事实模板。
- DeepSeek 输出禁止表达或段落数量不符：拒绝该结果并降级。
- 手动编辑违反商品禁用词规则：返回 422，不保存、不确认。

## 隐私与存储

- 不生成或持久化独立参考音频。
- 不向 DeepSeek、智算谷或对象存储发送本地解码出的 PCM。
- 只把转写后的文本发送给 DeepSeek。
- Whisper 模型权重可缓存；缓存中不包含用户视频或音频。

## 测试

- PCM 解码参数为 16 kHz、单声道、32 位浮点并从 stdout 读取。
- Whisper 输出能够正确对齐现有语音段。
- DeepSeek 请求包含参考原台词、新商品事实和“事实优先”规则，不包含图片或音频。
- 长袖参考台词与短袖新商品的用例中，提示词要求保留句式并替换冲突事实。
- 转写失败、无音轨和空转写均能降级且项目仍进入待确认状态。
- 脚本更新 API 保留时间轴，拒绝空行、数量变化和禁止表达。
- 前端显示原/新台词对照，并在未保存时阻止确认生成。
- 完整测试、类型检查和演示冒烟流程通过；验证期间不提交真实付费视频任务。

## 非目标

- 不克隆参考人物声音。
- 不把参考音频作为 Seedance 的单独输入。
- 不承诺逐字复制原视频台词。
- 不自动修改已经完成分析的旧项目；新流程对重新分析或新建项目生效。

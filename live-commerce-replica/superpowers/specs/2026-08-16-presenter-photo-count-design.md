# 指定模特照片数量调整设计

## 目标

将“指定模特”模式的人物参考照片数量从 3–5 张调整为 1–5 张，让只有一张可用人物面容照片的用户也能创建项目。

## 规则

- 指定模特模式至少上传 1 张、最多上传 5 张同一位授权成年人物照片。
- 参考视频超过 15 秒时仍强制使用指定模特模式，但只要求至少 1 张人物照片。
- 模型生成人物模式继续禁止上传人物照片。
- 单张图片 30 MB、商品图片 1–9 张等现有规则保持不变。
- 本次只调整数量规则，不新增人脸识别、清晰度判断或成年身份自动检测。

## 界面与接口

- 新建项目页的人物上传标题、引导文案和提交校验统一显示“1–5 张”。
- 后端作为权威校验：0 张或超过 5 张返回 422；1–5 张允许创建项目。
- 超过 15 秒且选择模型生成人物时，错误提示改为要求上传 1–5 张指定模特照片。
- README 的产品说明同步更新为 1–5 张。

## 验收

- API 测试证明指定模特模式只上传 1 张人物照片时可以创建项目。
- API 测试继续证明 0 张人物照片会被拒绝。
- 表单状态测试证明指定模特模式显示“上传 1–5 张同一位成年模特照片”。
- 全量测试、TypeScript 类型检查和演示模式冒烟测试通过。

## 兼容性

已有项目数据无需迁移。旧项目中的 3–5 张人物照片仍然符合新规则；变化只影响新建项目时的上传校验。
